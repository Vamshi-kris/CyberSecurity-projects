SubFinder

Passive subdomain enumeration via certificate transparency logs

How it works

1. Discovery: Queries crt.sh certificate transparency logs to find subdomains associated with the target domain.

2. Filtering: Cleans the data, removes wildcards, and deduplicates the results.

3. Live Check: Performs concurrent DNS resolution (A/AAAA records) to verify which subdomains are actively pointing to an IP.
